## 与 C 的分工边界（别重复写）

C 已有 `tests/test_eval_entry_contract.py` 25 条契约用例，覆盖：字段齐全、JSON 往返、
序号连续、HTTP 400/413/429、`/health`、`/schema` 等**结构层**验证。

本表只写**评测侧**增量：

1. 失败语义的黑盒验证（不抛异常、超长拒绝、工具失败不改 ok）
2. 引用与指标的可信度（编号对齐、指标自洽、编造引用）
3. 安全对抗与可复现性（越狱、降级、同输入同结果）

**不要**再写「字段是否存在」「JSON 能否序列化」这类结构用例——那是 C 的地盘。
